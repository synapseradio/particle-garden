Particle Garden - how to run it on Linux
========================================

1. Extract this archive. Right-click it in your file manager and choose
   Extract Here.

2. Let the file run as a program. Right-click particle_garden, open
   Properties, then Permissions, and turn on "Allow executing file as
   program". The wording differs between file managers. In a terminal this is:

       chmod +x particle_garden

3. Double-click particle_garden, or run ./particle_garden

4. A browser window opens with the garden in it. If you started the app from a
   terminal, keep that terminal open. Closing it stops the app.

Nothing is installed, and nothing needs root. To remove the app, delete the
folder you extracted.


If no browser window appears
----------------------------
Install Chrome, Chromium or Microsoft Edge. The app needs one of them to draw.

If it says the address is already in use
----------------------------------------
Close whatever else is using port 8089, then start the app again.
