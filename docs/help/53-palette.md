# Palette

The species colors, generated from the scheme buttons above these sliders.
Pick a scheme, then adjust:

- `paletteSaturation` — how vivid every species color runs.
  Interacts with: the scheme buttons (Open Color ignores it); halo tint;
  the grade's Saturation.
- `paletteLightness` — how bright every species color runs.
  Interacts with: the scheme buttons (Open Color ignores it); halo tint;
  Exposure.

Editing a single species by hand switches the palette to Custom until a
scheme button regenerates it.
