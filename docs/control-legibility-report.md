## Calibration: where each threshold sits

Each threshold sits inside the measured gap between the must-pass and must-fail anchor sets.

SPAN_MIN=0.15: must-fail edge rdFeed, span 0.131 on its pre-joint default slice; must-pass edge sphViscosity, 0.667 (the smallest of the must-pass set). Placed near the fail edge so the modest-but-live resolved-deposit response (0.211) stays outside the remedy net; every must-pass control clears the bar by at least 4x.

LIVE_FRACTION_MIN=0.7: must-fail edge rdKill, 0.514; must-pass edge 1.000 (the whole must-pass set). 0.70 sits between, above the fail edge by a third, and leaves expAttractionBeta's measured 0.875 — a live control with a short flat tail — clear of the bar.

CLIFF_MAX=0.25: kept at the provisional value, which the measurement showed already inside the gap: must-pass cliffs reach 0.020; the must-fail edge (rdFeed) measured 1.364.

RESPONSE_EPSILON=0.0001: unmoved by calibration — neither anchor set separates on it, so the provisional value stands until a measurement gives it an edge to sit against.
